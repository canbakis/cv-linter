## [0.1.0] - 2026-09-12

### Added

- Deterministic extraction and linting for PDF, DOCX, and Markdown CVs.
- English and Swedish spelling checks with operation-scoped allow words.
- JSON CLI commands for linting and text extraction.
- Equivalent local stdio MCP tools for host-assisted CV review.
- Evidence-grounded host skill and synthetic cross-format regression fixtures.
- Tag-driven GitHub releases with native archives, installers, checksums, and
  artifact attestations.
- A Claude plugin and a self-contained Claude Desktop extension for supported
  macOS and Windows systems.
